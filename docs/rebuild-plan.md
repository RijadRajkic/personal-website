## Key Decisions

| Decision           | Choice                                | Rationale                               |
| ------------------ | ------------------------------------- | --------------------------------------- |
| Tailwind version   | v4 (CSS-only, `@theme`)               | No config file, native CSS vars, modern |
| PostCSS            | `@tailwindcss/postcss` only           | v4 handles imports + prefixing          |
| Default colors     | Kept alongside custom palette         | Need gray/white/black utilities         |
| Migration approach | Fresh install, not upgrade            | Cleaner than migrating Pages Router     |
| Notion runtime     | `@notionhq/client`                    | Standard SDK, server-only               |
| Notion dev-time    | Notion MCP in VS Code                 | DB creation, content seeding            |
| Animations         | Copy from bussines-by-bega            | Centralize later across projects        |
| Component library  | None — hand-built                     | Full control, zero dependency bloat     |
| Forms              | react-hook-form + ValidationResult<T> | Proven pattern from bussines-by-bega    |

## Notion DB Schemas

### Projects

title, slug (Rich Text), category (Select: Full-Stack Platform/Enterprise System/Open Source/Tool), description (Rich Text), tech_stack (Multi-Select), status (Select: Published/Draft), featured (Checkbox), sort_order (Number), cover_image (Files & Media), live_url (URL), source_url (URL), year (Select)

### Blog Posts

title, slug (Rich Text), excerpt (Rich Text), category (Select), status (Select: Published/Draft), published_date (Date), cover_image (Files & Media)
